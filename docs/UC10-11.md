# UC10 — Versionamento e Integração Contínua

## Git Flow
- main: versão de produção;
- develop: integração;
- feature/nome: desenvolvimento isolado;
- release/versao: preparação de entrega.

## Commits
Utilizar Conventional Commits:
feat, fix, docs, test, refactor, build e ci.

Pull Requests devem incluir descrição, evidências, testes executados
e revisão antes da integração.

O workflow .github/workflows/ci.yml executa Jest e Maven
em push e pull request para main e develop.

# UC11 — Testes e Melhoria Contínua

A suíte Node é executada com npm test.
Os testes Java são executados com Maven e JUnit.

## Caixa branca
- autonomia de veículos;
- limites de carga;
- validação de pagamentos;
- comportamento de pilha e fila.

## Caixa preta manual
- criar, editar e desativar produto;
- cadastrar cliente e validar e-mail;
- rejeitar senha curta;
- cadastrar e excluir funcionário;
- pesquisar registros;
- verificar mensagens de confirmação e erro.

Os resultados reais devem ser registrados após a execução.
Não registrar teste como aprovado antes de executá-lo.
