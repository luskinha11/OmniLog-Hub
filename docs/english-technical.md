## Resumo técnico em inglês
**OmniLog Hub is an integrated logistics management platform. It connects customers, products, warehouses, inventory, sales orders and deliveries. The web interface communicates with a REST API built with Node.js and Express. The API uses MySQL to store data and manage stock reservations. Administrators manage the catalog, while operators update orders and delivery statuses. The system also includes route-planning and three-dimensional warehouse-allocation algorithms.**

## Tradução para português
O OmniLog Hub é uma plataforma integrada de gestão logística. Ela conecta clientes, produtos, armazéns, estoque, pedidos de venda e entregas. A interface web se comunica com uma API REST desenvolvida com Node.js e Express. A API utiliza MySQL para armazenar dados e administrar reservas de estoque. Administradores gerenciam o catálogo, enquanto operadores atualizam pedidos e status de entrega. O sistema também inclui algoritmos de planejamento de rotas e alocação tridimensional em armazéns.
